# PROFIT

> **Your Fitness. Your Progress.**

PROFIT is a comprehensive Flutter fitness and gym management application built with clean architecture, modern responsive design, dark charcoal and Electric Lime aesthetic, and 16 dedicated user and administrative workflows.

## Key Highlights
- **16 High-Fidelity Mobile Screens**: Splash, Onboarding, Authentication, Home Dashboard, Workout Roadmap, Exercise Detail, Exercise Library, Progress Tracking, Nutrition & Macros, Dedicated Trainer Section, Membership Management, User Profile, Notifications, Settings, Admin Operations Console, and AI Fitness Coach.
- **Electric Lime Branding**: High-contrast modern athletic palette (`#D4F63D` Electric Lime on `#0F1216` Charcoal).
- **Domain Calculations**: Accurate 1RM calculators (Epley formula), BMI classifications, macro energy ratios, and volume tracking.

## Getting Started

Run with Flutter:
```bash
flutter pub get
flutter run
```

Run test suite:
```bash
flutter test
```
